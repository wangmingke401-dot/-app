# 黑马记账 · 使用说明

一款本地桌面记账软件：记下每一笔花销，按月查看账单，用图表看清钱花在了哪里。**所有数据只保存在你自己的电脑上，不联网、不上传。**

## 一、如何安装

1. 双击 `dist` 文件夹里的 **黑马记账-Setup-1.0.0.exe**。
2. Windows 可能会提示"已保护你的电脑"（因为软件没有购买数字签名证书）——点击 **「更多信息」→「仍要运行」** 即可，这是正常的。
3. 按安装向导提示完成安装，桌面会出现「黑马记账」图标，双击即可使用。

## 二、如何使用

- **记一笔**：打开软件，点右上角橙色「＋ 记一笔」按钮 → 输入金额 → 先选大类（如餐饮）再选小类（如午餐）→ 选日期 → 可填备注 → 保存。
- **看账单**：左侧「账单」页按日期列出每笔支出，顶部可以翻看任意月份；点击任意一笔可以**修改**或**删除**（删除有确认提示，防止误删）。
- **看统计**：左侧「统计」页可以看任意月份的：总支出、笔数、日均支出、分类占比图、分类排行、近 6 个月趋势。

## 三、数据在哪里？如何备份？

- 所有账目存在电脑上的一个数据库文件里：`C:\Users\你的用户名\AppData\Roaming\黑马记账\heima-accounting.db`
- **备份**：复制这个文件保存到别处即可；换电脑时把这个文件放回同样位置，账目就全回来了。
- 隐私：软件不联网，数据不会上传到任何地方。

## 四、以后想改功能怎么办？

直接打开 Claude Code，在项目文件夹（d:\黑马记账app）里用中文描述你的想法即可，例如：
- "我想加导出 Excel 功能"
- "我想自己添加分类"
- "统计页想加一个对比上月功能"
